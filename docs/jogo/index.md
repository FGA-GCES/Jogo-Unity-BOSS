# Diários de Sofia - Documentação

Bem-vindo à documentação oficial do jogo **Diários de Sofia**!

## Sobre o Jogo

"Diários de Sofia" é um jogo educacional que combina narrativa envolvente com mecânicas de jogabilidade para proporcionar uma experiência imersiva. Através da jornada de Sofia, os jogadores exploram conceitos importantes enquanto vivenciam uma história cativante.
