    🎮 Diários de Sofia - Unity for Women

    Projeto Open Source de Desenvolvimento de Jogos com Unity

    Universidade de Brasília (UnB) - GCES 2025.1

    🌟 Sobre o Projeto

    O Diários de Sofia é um projeto educacional open source desenvolvido para promover diversidade e inclusão na tecnologia através do desenvolvimento de jogos. Criado como parte da disciplina de Gerenciamento de Configuração e Evolução de Software (GCES) da UnB, este projeto combina:

    • 🎯 Aprendizado prático de desenvolvimento de jogos com Unity
    • 👥 Colaboração em equipe usando metodologias ágeis
    • 🔧 Boas práticas de engenharia de software
    • 🌍 Código aberto para beneficiar a comunidade

    🎮 O Jogo

    "Diários de Sofia" é um RPG narrativo 2D em pixel art que combina puzzles e combate para conscientizar sobre igualdade e justiça social. Com perspectiva top-down inspirada em clássicos, o jogo oferece uma experiência envolvente que vai além do entretenimento.

    🎯 Objetivos do Projeto

    📚 Aprendizado

    • Aplicar conceitos de GCES na prática
    • Dominar ferramentas de controle de versão
    • Implementar CI/CD e DevOps
    • Praticar metodologias ágeis

    🌍 Impacto Social

    • Promover diversidade na tecnologia
    • Criar conteúdo educativo sobre igualdade
    • Formar uma comunidade inclusiva
    • Compartilhar conhecimento através do código aberto

    🛠️ Técnico

    • Desenvolver um jogo completo em Unity
    • Implementar arquitetura limpa e escalável
    • Documentar processos e decisões
    • Criar pipelines de qualidade de código

    🚀 Como Começar

    👀 Quero apenas jogar

    1. Acesse as releases do projeto
    2. Baixe a versão mais recente
    3. Execute o jogo e divirta-se!

    💻 Quero contribuir

    1. Leia o Código de Conduta
    2. Siga o Guia de Contribuição
    3. Configure seu ambiente de desenvolvimento

    📖 Quero aprender

    1. Participe dos workshops
    2. Veja nosso processo de desenvolvimento
    3. Acompanhe nossos roadmaps
