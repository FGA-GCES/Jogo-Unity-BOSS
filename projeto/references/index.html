    19/04/2025 0.1 Adicionando Artes e referências Artur Bartz

    Para o desenvolvimento do projeto, estão sendo utilizadas artes de uso livre em conjunto com artes próprias desenvolvidas pelo nosso time.

    Ninja Adventure Asset Pack

    O Ninja Adventure Asset Pack é um pacote de artes de uso livre que estamos utilizando para criar cenários e NPCs.

    A licença desse Asset Pack é o CC0 (Creative Commons Zero). A CC0 é uma licença em que é permitido usar o uso livre das artes, até mesmo para fins comerciais, sem a necessidade de atribuir créditos.

    Artstation

    O ArtStation.com é um pacote de artes de uso livre que estamos utilizando para criar blocos. O Autor é o Andreas Paul, conhecido por ser um entusiasta em artes em 3D.

    FoxelDev

    FoxelDev.Itch.Io é um pacote de artes de uso livre de acordo com a licença: CCO 1.0 - Universal, do autor Foxel Games na qual usamos para pegar a referência do nosso livro da tela inicial e para usar futuramente dentro do jogo.
